# 📡 LLM Radar

_This page is generated automatically every Monday by the **LLM Radar** GitHub Action
(`.github/workflows/llm-radar.yml` → `radar/llm_radar.py`)._

It tracks the latest releases of the key tools in the LLM ecosystem (training, fine-tuning,
inference, quantization, agents, RAG, SDKs) plus the newest LLM papers on arXiv, and links each
tool to the chapter of this course where you build the same idea from scratch.

> ⏳ Pending first run. After you push the repo, open **Actions → LLM Radar → Run workflow**
> to populate this page immediately.

To follow a new tool, add it to [`radar/watchlist.json`](../radar/watchlist.json).
